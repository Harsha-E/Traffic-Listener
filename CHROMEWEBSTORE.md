## 2. Store Listing Copy

### Summary (Short Description - max 132 chars)
Inspect local web application network traffic, analyze endpoint patterns, and learn HTTP request structures safely.

### Detailed Description

NetListener is a developer and cybersecurity education tool that helps you inspect, understand, and map how web applications communicate with local backend services.

Whether you are debugging a local API, learning about HTTP request lifecycles, or studying application security concepts, NetListener provides a clean, informative view of your local browser traffic.

KEY FEATURES:

• Real-Time Traffic Inspection: View HTTP methods (GET, POST, PUT, PATCH, DELETE, OPTIONS), status codes, durations, and resource types for requests made to your local development environment.
• Endpoint Intelligence: Automatically groups requests by origin and route pattern (e.g., abstracts /users/42 into /users/:id) to help you map API structures and identify frequent or failing endpoints.
• Privacy-First Credential Redaction: Automatically masks sensitive query parameters (API keys, tokens, passwords) and authorization headers so you can study request formats without leaking credentials.
• Educational Security Auditing: Inspect response security headers including CORS permissions, Content-Security-Policy, and MIME-type options.
• Flexible Export Options: Export sanitized traffic logs in JSON or CSV format for documentation and reports.
• Dedicated DevTools Panel: Inspect requests directly inside Chrome Developer Tools with full response body viewing.

DESIGNED FOR PRIVACY & SAFETY:
• NetListener defaults exclusively to monitoring localhost and 127.0.0.1. Unrelated websites are never monitored.
• Zero external data transmission: all captured traffic remains strictly inside your local browser.
• Clear history at any time with a single click.

## 3. Permissions Justifications

### `webRequest`
**Justification:** Needed to passively observe HTTP request metadata (URL, method, status code, duration, resource type, and headers) generated by web applications within permitted local development origins (localhost and 127.0.0.1).

### `storage`
**Justification:** Needed to store captured request metadata locally on the user's device so that request history is preserved when the extension popup is closed or when the background service worker goes idle.

### `host_permissions` (`http://localhost/*`, `https://localhost/*`, `http://127.0.0.1/*`, `https://127.0.0.1/*`, `https://*.firebaseio.com/*`, `https://firestore.googleapis.com/*`, `https://*.cloudfunctions.net/*`)
**Justification:** Restricts local development traffic monitoring strictly to the user's local servers (localhost and 127.0.0.1), while allowing optional transmission of user-initiated structured traffic reports to Firebase when the user explicitly clicks the "Send log" button. External websites are excluded from passive traffic monitoring.

## 4. Privacy & Data Use Disclosure

- **Single Purpose:** Inspecting local web application network traffic for development and cybersecurity education.
- **Data Collection:**
  - Personally Identifiable Information: None collected.
  - Authentication Credentials: Automatically redacted and masked; none stored or transmitted.
  - Web Browsing History: Excluded. Only local development requests (`localhost` and `127.0.0.1`) are captured.
- **External Data Transmission:** NetListener does not connect to any external server or analytics service. 100% of data remains local.
